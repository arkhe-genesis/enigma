# enigma.audio

The layered, multi-channel audio engine (installed with the optional `[audio]`
extra).

- [USAGE.md](USAGE.md): the runtime API, and the out-of-process daemon
  (`AudioManager.spawn()`) that keeps mixing off the main GIL.
- [AUDIO_CONFIG.md](../docs/AUDIO_CONFIG.md): the JSON configuration (classes,
  library, devices).
- [Audio API reference](../docs/api/AUDIO_CLASS.md): the generated audio proxies.
