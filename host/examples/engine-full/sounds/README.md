# Example UI sounds

Three short interface blips used by the `--audio` demo in
[`../application/example_app.py`](../application/example_app.py):

| File | Event |
|------|-------|
| `ui/clicks/click.wav` | `button_click` |
| `ui/toggles/toggle.wav` | `switch_toggle` |
| `ui/knobs/knob.wav` | `knob_adjust` |
